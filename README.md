# Rubiks Solver

Goal: Use machine learning to solve Rubiks cubes of size n = 2, 3. 

## Road Map

### 2x2
- [x] Create a state class for the cube which contains only canonical scrambles (a scramble is unique regardless of rotation).
- [x] Create the 3D model of the cube on the front end. 
- [ ] Create move animations syncing with the back end representation. 
- [ ] Train a neural network to find the optimal solution.

### 3x3
- [ ] Develop interactable 3x3 cube.
